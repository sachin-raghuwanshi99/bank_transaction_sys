# Bank Transaction Management System

A backend application for managing bank accounts and transactions.

## Features

- User registration and login
- Bank account management
- Deposit and withdrawal transactions
- Transaction history
- Secure authentication
- Email notifications

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- Nodemailer
